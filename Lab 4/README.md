# **Lab 4: Reusable Barrier**

This is my solution for the Reusable Barrier lab. It implements a Two-Phase Barrier (Turnstile pattern) using buffered channels and a Mutex. This ensures the barrier can be safely used inside loops without causing deadlocks or race conditions.

## **Setup & Running**

This code allows multiple iterations (loops) of synchronization.

1. **Run the code(Open a terminal in this directory and run):**

```bash
go run ReusableBarrier.go
```
